# Rumba Reader : application Python et port Wix

Depuis la racine du dépôt, installer `desktop/requirements.txt` dans un environnement virtuel puis lancer `python desktop/app.py`. Vérifier Tk avec `python -m tkinter`.

Le [guide de démarrage](../docs/getting-started.fr.md) décrit l'utilisation et les exports ; le [guide algorithmique](../docs/algorithm.fr.md) précise le sens des scores. `scripts/` contient les commandes optionnelles de construction macOS et Windows ; les applications compilées et les polices ne sont pas distribuées dans les sources.

L'intégration [Wix Velo](wix_velo/README.md) dispose de sa propre documentation.
