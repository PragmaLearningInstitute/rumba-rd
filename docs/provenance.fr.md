# Provenance et périmètre

RUMBA.RD réunit le navigateur `rumba-rd-light.html`, son moteur et exporteur partagés, l'application Python Rumba Reader et son port Wix Velo. Les articles HTML du site sont conservés dans `docs/original-site/` à titre d'archives ; leurs ressources et menus dépendaient du site PLI. Les guides Markdown décrivent cette édition autonome.

Les dépendances installées, environnements virtuels, binaires, données utilisateur, sauvegardes et polices dont la redistribution n'a pas été vérifiée sont exclus. Les images de marque présentes proviennent du projet ; les noms et logos n'impliquent pas l'approbation d'un fork par PLI.

L'édition publique corrige les chemins des modules web, désactive la télémétrie par défaut et préserve les chiffres, tirets bas et caractères Unicode dans le découpage. Les tests associent conservation du texte et échappement HTML. Ils ne valident pas une efficacité pédagogique.

L'algorithme est une mise en forme heuristique. Les mentions historiques d'IA, de Zipf ou d'amélioration de la lisibilité doivent être lues avec les définitions précises du [guide de l'algorithme](algorithm.fr.md). Le score calculé sur le texte d'entrée ne prouve pas un gain après traitement.

Consulter [RUMBA.RD sur le site officiel](https://pragmalearninginstitute.com/rumba-rd) et [la documentation PLI](https://pragmalearninginstitute.com/outils/documentation) pour le contexte, et `CITATION.cff` pour citer le code.
